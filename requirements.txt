# 4. Card Data Model

Each card must contain exactly these primary fields:

* `id`
* `title`
* `subtitle`
* `attack`
* `defense`
* `action`
* `image`
* `zone`

Use a TypeScript model/interface similar to:

```ts
interface Card {
  id: string
  title: string
  subtitle: string
  attack: number
  defense: number
  action: string
  image: string | null
  zone: Zone
}
```

The `Zone` type must contain exactly:

```ts
enum Zone {
  ATTACK = 'ATTACK',
  MIDFIELD = 'MIDFIELD',
  DEFENSE = 'DEFENSE'
}
```

The term must always be **"zone"**.

Do NOT call it:

* field zone
* field position
* football position
* battlefield position

The zone is a **visual card theme**, not a diagram or representation of a football field.
